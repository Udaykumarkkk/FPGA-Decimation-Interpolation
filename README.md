# FPGA-Decimation-Interpolation
FPGA-based multirate DSP system implementing decimation by 3 and interpolation by 12 using Xilinx FIR Compiler IP, Verilog HDL, Vivado, and Python FFT analysis.
# FIR-Based Decimation by 3 and Interpolation by 12

## Overview
This project implements a multirate DSP system using Xilinx FIR Compiler IP.

Features:
- Decimation by 3
- Interpolation by 12
- Q1.15 Fixed Point Processing
- 51-Tap FIR Filters
- Verilog HDL
- Vivado Simulation
- Python FFT Analysis

## Tools
- Xilinx Vivado
- Verilog HDL
- Python
- NumPy
- Matplotlib

## Signal Specifications
- Input Frequency: 1 MHz
- Sampling Frequency: 120 MHz
- Output Frequency: 1 MHz
- Final Sampling Rate: 480 MHz

Simulation waveforms and FFT plots are included in the Results folder.
